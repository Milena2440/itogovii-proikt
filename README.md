# 🌍 ClimateEye Bot: поиск признаков глобального потепления на фото

**Автор:** Милена  
**Тема:** Глобальное потепление и климатические изменения  

ClimateEye — это Telegram-бот, который с помощью компьютерного зрения анализирует присланные фотографии и определяет на них признаки глобального потепления. Бот не просто угадывает — он использует современную модель CLIP для семантического сравнения изображения с описаниями климатических явлений и возвращает результат вместе с уровнем уверенности алгоритма.

## 🎯 Возможности

*   **Распознавание признаков:** бот умеет находить на фото таяние льдов, засуху, лесные пожары, наводнения, аномальную жару, исчезновение снега и усыхание растительности.
*   **Оценка уверенности:** для каждого признака модель рассчитывает вероятность; бот показывает топ-3 совпадения и уровень уверенности в главном результате.
*   **Честность в ответах:** если модель не уверена ни в одном из признаков (уверенность ниже 60%), бот честно сообщит, что не нашёл свидетельств климатических изменений на этом снимке.
*   **Наглядность:** результат сопровождается эмодзи и кратким списком других возможных совпадений.

## 🧠 Как это работает

В основе бота лежит модель **CLIP (Contrastive Language–Image Pretraining)** от OpenAI. В отличие от обычных классификаторов, CLIP умеет понимать смысл картинки, сравнивая её с текстовыми описаниями.

1.  Пользователь отправляет фото в Telegram.
2.  Бот скачивает изображение и конвертирует его в нужный формат.
3.  Модель сравнивает фото с набором текстовых промптов (например, «фото засухи, высохшей земли» или «фото тающих ледников»).
4.  Алгоритм вычисляет степень схожести для каждого класса и выбирает наиболее вероятный вариант.
5.  Бот отправляет пользователю понятный ответ с эмодзи, названием признака и процентом уверенности.

Такой подход позволяет не обучать собственную нейросеть с нуля, а использовать предобученную модель для гибкой классификации.
